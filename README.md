# M22 — نظام إدارة أعمال لويندوز (على طريقة Dexef)

برنامج ويندوز (C# WinForms / .NET 8) بواجهة عربية بالكامل وقاعدة بيانات SQL Server.

## الوحدات
- **الأصناف والمخازن**: دليل الأصناف، المخازن، أرصدة المخزون (حركات مخزنية تلقائية).
- **المبيعات والمشتريات**: فواتير ومرتجعات (نقدي / آجل / جزئي)، العملاء والموردين، كشف حساب، سجل المستندات مع الحذف.
- **الخزينة والمصروفات**: استلام/دفع نقدي، المصروفات والإيرادات حسب البند، الخزائن والبنوك.
- **الحسابات والتقارير**: شجرة حسابات، قيود يومية تلقائية لكل مستند، دفتر أستاذ، ميزان مراجعة، قائمة دخل، تقارير مبيعات/مشتريات، تصدير CSV.
- مستخدمون وتسجيل دخول.

## التشغيل
1. ارفع الملفات على GitHub، وسيبني **GitHub Actions** ملف `M22.exe` (من تبويب Actions ← آخر تشغيل ← Artifacts).
2. شغّل `M22.exe` على جهاز عليه SQL Server (أو SQL Server Express).
3. عند أول تشغيل أدخل اسم السيرفر (مثال `.\SQLEXPRESS`)، وسيُنشأ البرنامج قاعدة البيانات `M22DB` والجداول تلقائياً.
4. الدخول الافتراضي: **admin / admin** (غيّر كلمة المرور من الفهرس ← المستخدمين).

## ملاحظات
- رصيد أول المدة للعملاء والموردين يظهر في الكشوف والأرصدة، ولا يدخل في القيود.
- حذف مستند يحذف قيوده وحركاته المخزنية، ولا يعيد سعر التكلفة المحدَّث من فاتورة الشراء.
- ملف الإعدادات `config.json` يُحفظ بجانب البرنامج.
